# v3 Rejected

This version must not be used in the application or for clinical education.

Reasons:

- One diagonal table was reused for maneuvers with different movement planes.
- Dix-Hallpike did not clearly show a backward descent along the table axis.
- Gufoni did not clearly show a lateral descent or distinguish the two sides.
- Epley included an incorrect visible head direction.
- Patient poses were rotated to fit the background instead of being generated in the correct table coordinate system.

The technical fixed-background check was insufficient and is not evidence of clinical correctness.
