# v4 Rejected

This version must not be used in the application or for clinical education.

- Character scale changes between poses.
- Hip position and body registration change between frames.
- The output cannot function as a coherent animation even where individual key poses look plausible.
- Visual comparison with videos did not include quantitative anchor and bone-length checks.

The replacement v5 prototype uses a programmatically rendered fixed skeleton, fixed hip coordinates, and rigid-length interpolation.
