# VERTIGO ─ めまい診療の書：設計書

作成日: 2026-08-20
対象: 研修医向け めまい診断トレーニング PWA

---

## 1. 目的

研修医が救急外来の当直医としてめまい患者を診察し、自分で診察法を選び、診断・治療・方針を決定し、患者の転帰をストーリーで受け取る学習ゲーム。教育内容は当院の HOWTO（めまい患者対応）に準拠する。

### 教育上の到達目標

1. GRACE-3 の3分類（AVS / s-EVS / t-EVS）を主訴と経過から立てられる
2. STANDING フロー（眼振の有無 → 方向 → 頭位眼振 → 起立歩行）で診察を組み立てられる
3. HINTS は AVS でのみ有効であり、t-EVS（BPPV疑い）に用いないと理解する
4. 起立歩行・継ぎ足歩行のチェックを全例で行う（指鼻試験より感度が高い）
5. MRI 適応を HOWTO の4条件で判断できる
6. **MRI（DWI）陰性は中枢性の除外にならない**と理解し、入院・再検・コンサルトを選べる
7. 耳石置換法（Epley / Lempert / Gufoni 向地性・背地性）を病態に応じて使い分けられる
8. 当院標準の対症療法を実施できる
   - 強い回転性めまい: アタラックスP 25mg + 生食50mL 15分でDIV
   - 嘔気: プリンペラン1A + 生食50mL 15分でDIV
   - ルーチン採血は不要。輸液は症状緩和のため開始する

## 3. コアメカニクス

### 3.1 隠れ所見システム（難症例の肝）

コマンドの粒度を細かくし、粗く診ると正常に見え、丁寧に診ると異常が出る構造にする。

| コマンド分割 | 粗い診察 | 細かい診察 | 該当症例 |
|---|---|---|---|
| 眼振：裸眼 / Frenzel眼鏡下 | 「明らかな眼振なし」 | 「ごく軽度の水平眼振」 | 11, 12, 15 |
| 歩行：普通歩行 / 継ぎ足歩行 / Romberg開眼・閉眼 / 片足立ち | 「ほぼ正常」 | 「継ぎ足歩行が著明困難」 | 11, 19 |
| 顔面感覚：片側ずつ / 両側同時刺激 | 「正常」 | 「左側がわずかに鈍い」 | 15 |
| 問診：主訴のみ / 誘発状況を掘る | 「めまいがする」 | 「ヨガで頸部を反らした瞬間に後頭部が裂けるように痛んだ」 | 14 |

「何を診るか」だけでなく「どこまで丁寧に診るか」が情報量とスコアを決める。

### 3.2 MRI適応判断（HOWTO 4条件）

診察終了後、以下を自己判定させ、各項目を採点する。判定材料は診察で拾えていないと分からない。

1. リスクファクターのある突然発症ではないか（高血圧・糖尿病・心疾患・動脈硬化・喫煙）
2. 眼振は末梢性として矛盾しないか（方向・固視による減弱）
3. 中枢性を疑わせる随伴症状や神経所見がないか
4. 起立時・歩行時のふらつきは強くないか

続いて撮像を選択：撮らない / 頭部CT / MRI-DWI / MRI+MRA / CTA / 純音聴力検査

- 症例11（小脳出血）: CTが第一選択。MRIでも減点しないが「出血評価に難あり」と返る
- 症例14（椎骨動脈解離）: DWI単独では永久に陰性。CTA/MRA必須
- 症例1〜5（BPPV）: 撮ると減点

### 3.3 MRI陰性からの第二幕（最重要）

難症例では正しく撮っても DWI 陰性が返る。ここが最大の分岐点。

- 末梢性として帰宅処方 → バッドエンド（数日後に増悪して再搬送）
- 経過観察入院 → 第2日の再検MRIで病変出現 → 確定診断へ（正解）
- 神経内科・脳神経外科にコンサルト → 加点
- CTA/MRA追加 → 症例14はここでしか正解に到達しない

逆に、BPPV・前庭神経炎で「念のため入院」を選ぶと軽い減点（医療資源の適正利用）。これにより「迷ったら入院」戦略を封じる。

### 3.4 帰宅は一律に減点しない（症例ごとのフラグ）

「高齢でリスク因子があるからMRIを撮った → 陰性 → 失調もなく中枢性の可能性は高くない → 末梢性めまいとして帰宅」は
**正解**として扱う。減点＋バッドエンドになるのは、失調がある／中枢性所見が揃っている症例で帰宅させた場合のみ。

症例データに次の2フィールドを持たせ、症例ごとに切り替える。

- `imagingStance`: `'indicated'`（撮るべき・撮らないと減点）／`'optional'`（高齢・リスク因子ありで念のため撮るのは妥当・減点しない）／`'unnecessary'`（典型的な末梢性で不要・撮ると軽く減点）
- `dischargeAfterNegativeOk`: 画像陰性後に末梢性として帰宅してよいか。`true` なら帰宅が正解、`false` なら見逃しとして最悪の転帰

これにより「所見が微妙 ＝ 中枢性 ＝ MRI＋入院」というメタ読みが成立しなくなる。

## 4. コマンド体系

全症例共通のコマンドマスタを1箇所に定義し、症例データは「そのコマンドを叩いたら何が返るか」と「スコア寄与」だけを持つ。未定義のコマンドは既定文（「特に異常を認めない」）を返す。

### きく（問診）
発症様式・持続時間・誘発因子・随伴症状・耳症状・既往歴とリスクファクター・内服薬・社会歴（喫煙）・家族の目撃情報

### みる（眼）
自発眼振（裸眼）／自発眼振（Frenzel眼鏡下）／固視による眼振減弱／注視眼振（左右30°）／Dix-Hallpike 右・左／Supine Head Roll 右・左／Head Impulse Test／Test of Skew

### しらべる（神経・全身）
CPSS／指鼻試験／踵膝脛試験／回内回外／普通歩行／継ぎ足歩行／Romberg（開眼・閉眼）／片足立ち／脳神経（複視・眼球運動・顔面感覚 片側ずつ・顔面感覚 両側同時・嚥下と咽頭反射・Horner）／聴力（音叉）／バイタル／両上肢血圧／起立試験

### けんさ
血液検査／心電図／頭部CT／頭部MRI-DWI／MRA／CTA／純音聴力検査／心エコー／再検MRI（第2日）

### てあて（対症・診察中に可）
輸液／アタラックスP 25mg + 生食50mL 15分DIV／プリンペラン1A + 生食50mL 15分DIV

### 治療フェーズの選択肢
Epley法（右/左）／Lempert法（右/左）／Gufoni法 向地性（右/左）／Gufoni法 背地性（右/左）／ステロイド（PSL 1mg/kg）／脳卒中プロトコル＋緊急コンサルト／抗血小板療法／抗凝固の再開・調整／トリプタン／イソバイド・ベタヒスチン／減塩指導／帰宅処方（セファドール・五苓散・トラベルミン）／前庭リハ指導（Brandt-Daroff・Cawthorne-Cooksey）／頸部固定／禁煙指導

## 5. スコアリング

100点満点＋減点。

| 区分 | 配点 | 内容 |
|---|---|---|
| 診察プロセス | 30 | required 項目の実施率。recommended は加点 |
| めまいタイプ判定 | 5 | AVS / s-EVS / t-EVS の正誤 |
| 画像適応判断 | 15 | HOWTO 4条件の判定＋撮像選択 |
| 画像陰性後の方針 | 20 | 帰宅／入院／再検／コンサルト／血管評価 |
| 診断 | 20 | 疾患15 ＋ 患側5（疾患正解・左右誤りは部分点） |
| 治療 | 10 | 必須治療の実施 |

### 減点

| 行為 | 点 |
|---|---|
| 起立歩行・継ぎ足歩行の未実施 | -10 |
| t-EVS 疑いに HINTS を実施 | -5 |
| ルーチン血液検査（脳卒中疑いなし） | -3 |
| BPPV に頭部MRI | -5 |
| 中枢性症例に耳石置換法 | -15 |
| 失調・中枢性所見がある症例で帰宅させた（`dischargeAfterNegativeOk: false`） | -20（バッドエンド確定） |
| 良性疾患で不要な入院 | -3 |

画像陰性後の帰宅は一律に減点しない。`dischargeAfterNegativeOk: true` の症例（失調がなく中枢性の可能性が高くない）では帰宅が正解として満点になる。3.4 を参照。

### ランク

S(95+) / A(85+) / B(70+) / C(50+) / D(50未満)。ドラクエ風のレベルアップ演出。

## 6. エンディング分岐

診断・治療・方針の組み合わせで症例ごとに4分岐。

- best: 正診＋適切治療＋適切な方針
- good: 診断は正しいが治療または方針が不十分
- bad: 誤診したが重大な転帰は回避
- worst: 中枢性の見逃し帰宅など。画面が赤くフラッシュし全滅ジングル

- UI: 紺背景＋2px白枠のドラクエ風ウィンドウ。日本語ピクセルフォントは容量が大きいため system-ui ベース＋字間調整で「風」に寄せる

## 8. 症例セット

cases.md の症例1〜10（末梢性・BPPV）と vertigo_game_20_part3.js の症例11〜20（難易度の高い中枢性）を統合。
医学的監査と難易度バランスの調整により、**全15症例**とする。

### 中枢性は「微妙な症例」5例のみ

眼振がない症例は1例だけに絞り、残り4例は**眼振が末梢性と区別できない**微細眼振とする。
これにより「眼振が変だから中枢性」という短絡が効かなくなる。

| 症例 | 眼振 | 唯一の手がかり | 画像の罠 |
|---|---|---|---|
| 11 小脳出血（軽度・意識清明型） | 微細な左向き水平眼振（Frenzelでようやく） | 幅広基底歩行 | CTが第一選択 |
| 12 外側延髄症候群（不完全型） | 微細な右向き水平眼振・方向不変に見える | 「口の右側がピリピリする」のみ | DWIは24〜48時間後に陽性化 |
| 14 椎骨動脈解離（初期） | 微細な左向き水平眼振 | 後頭部痛＋頸部痛＋頸部過伸展の誘因 | DWIでは永久に陰性・CTA必須 |
| 15 橋梗塞（顔面しびれのみ） | 微細な左向き水平眼振 | 両側同時刺激でのみ分かる顔面感覚低下 | DWI偽陰性 |
| 19 小脳梗塞（PICA領域・極小） | **なし（唯一の眼振なし症例）** | 継ぎ足歩行とRomberg閉眼のみ | 初回DWI陰性 → 翌日再検で出現 |

### 削除した症例

| 症例 | 理由 |

| 17（外側橋脳梗塞） | 末梢性顔面神経麻痺の記載が本文とkeyPointsで矛盾。医学的に整理できないため削除 |
| 18（中脳梗塞） | 外転神経核は橋にあり中脳では説明できない。削除 |
| 13（小脳梗塞・小面積） | 眼振なし症例を1例に絞るため削除 |
| 16（小脳TIA） | 発作間欠期は所見が全て正常＝実質「眼振なし」症例のため削除 |
| 20（鎖骨下動脈盗血症候群） | 眼振なし症例を1例に絞るため削除。「上肢運動で誘発されるめまい」は良い教材なので、将来差し替え候補 |
