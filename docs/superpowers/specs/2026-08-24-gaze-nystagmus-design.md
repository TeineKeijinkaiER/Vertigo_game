# 注視眼振で左右両方の注視を描く 設計書

日付: 2026-08-24

## 背景

注視眼振（`eye_gaze`）の所見は、これまで片方向の注視しか描いていなかった。`NystagmusSpec` が `gazeOffset` を1つしか持たないためである。

そのためキャプションが「左方注視では左向きに変わる ＝ 方向可変性」と主張していても、画面には右方注視の1枚しか出ず、学習者は主張を絵で確認できなかった。方向可変性は中枢性の赤旗そのものなので、そこが確認できないのは教材として弱い。

## 決定事項

### 縦に2枚並べる

右方注視と左方注視を上下に並べる。各図が全幅を使えるので、スマートフォンでも眼球とキャプションが読める。横並び（既存の `exam-duo`）は一目で対比できるが、375px 幅では各図が約180pxとなり眼球も文字も小さくなりすぎる。

### 全5症例に入れる

`eye_gaze` に眼振を持つのは5症例で、2つのパターンに分かれる。

| 症例 | パターン |
| --- | --- |
| 6 前庭神経炎、7 メニエール病 | 方向不変・振幅のみ変化（Alexanderの法則） |
| 8 前庭性片頭痛、9 Wallenberg、11 小脳出血 | 方向可変（中枢性） |

**方向可変の3症例だけを2枚にしてはいけない。** 枚数を見ただけで中枢性と分かり、答えが漏れる。これは [`actions.ts`](../../../src/data/actions.ts) の `asksSide` に書かれている「症例側の属性で出し分けると答えが漏れる」と同じ問題である。

全5症例を2枚にすれば、末梢性では「向きが変わらず振幅だけ変わる」ことが絵になり、Alexanderの法則の教材にもなる。

## データモデル

[`src/data/types.ts`](../../../src/data/types.ts) の `NystagmusSpec` に1段だけの入れ子を追加する。

```ts
/** 注視眼振で反対方向を見たときの所見。指定すると2枚並べて描く */
gazeOpposite?: Omit<NystagmusSpec, 'gazeOpposite'>
```

`Omit` で多段の入れ子を防ぐ。未指定の眼振は従来どおり1枚で描かれるため、頭位検査や自発眼振には影響しない。

## 描画

[`src/components/Nystagmus.tsx`](../../../src/components/Nystagmus.tsx) の現在の本体を `NystagmusFigure` として切り出し、`Nystagmus` は `gazeOpposite` の有無で1枚か2枚かを決める。呼び出し側（`Exam.tsx` / `BppvLearn.tsx`）は変更しない。

あわせて `Eye` の `clipPath` の id を `useId()` で一意化する。現在は `clip-右眼` 固定で、同一画面に複数の眼振図があると id が重複する（BPPV学習画面では既に重複している）。両者の形状が同一なので今は偶然動いているだけで、2枚並べを増やす前に直しておく。`useId()` の戻り値はコロンを含むため、`url(#...)` に埋める前に除去する。

## 各症例の内容

- **症例6・7（末梢性）**: 左方注視も同じ向きのまま、振幅を正面より小さくする。右方注視 > 正面 > 左方注視 の順になり、Alexanderの法則がそのまま絵になる。
- **症例8・9・11（中枢性）**: 左方注視で水平成分の符号を反転する。症例9は垂直成分を残したまま水平成分だけ反転させる（単一の半規管では説明できない打ち方であることが中枢性の手がかりになる）。
- 所見テキストは既に左右両方を記述しているため変更しない。キャプションは1枚に1つの注視方向を述べる形に書き分ける。

## テスト

[`src/data/cases/index.test.ts`](../../../src/data/cases/index.test.ts) に不変条件を追加する。

- `eye_gaze` に水平成分があれば `gazeOpposite` を必ず持つ。枚数による答えの漏洩をそのまま検査にする。
- 左右の `gazeOffset` の符号が逆である。同じ方向を2枚描いていないことを担保する。

## スコープ外

- 正面（第一眼位）の注視は描かない。自発眼振のコマンドが既にその役割を持つ。
- 頭位検査・自発眼振の描画は変更しない。
